# Tara Tozer fundraising website preview

Live demo: https://mkal72.github.io/friend-website/

A responsive redesign of https://taraktozer.com/fundraising/ with the two listed programs, original images and referral links, business sponsorship ideas, and access to the original inquiry form.

## Local preview
Open index.html in a browser. No build step or dependencies required.

## Files
- index.html: page content
- assets/css/styles.css: responsive layout, entrance animations, reduced-motion styles
- assets/js/main.js: progressive scroll reveals
- assets/images/: four images from the original page

## Publishing
GitHub Pages publishes from the root of main. Push commits to main to deploy.

## Inquiry handling
The contact button opens the existing WordPress form on Tara’s original website so submissions retain their existing delivery. No form backend is hosted in this repository.

## Content notes
The source introduction mentioned three options, but only two programs were present, labelled Option One and Option Three. This preview presents the two listed programs in sequence. The blanket fundraiser is retained as an inquiry topic; no unverified program details have been added. Program rates are reproduced from the source, with its qualification notice. Source reviewed October 14, 2026. Google Fonts enhance typography; system fonts are fallbacks.
