# Friend Website

A lightweight, responsive website demo hosted on GitHub Pages.

Live site: https://mkal72.github.io/friend-website/

## Structure

- `index.html`: page content and layout
- `assets/css/styles.css`: responsive styles
- `assets/images/`: photos and illustrations
- `assets/js/`: space for future JavaScript
- `.nojekyll`: serves these files directly on GitHub Pages

## Local preview

Open `index.html` in your browser. No dependencies or build step required.

## Publishing

GitHub Pages publishes from the root of the `main` branch. Push changes to `main` to update the website. Use relative asset links so the site works under its repository URL.
